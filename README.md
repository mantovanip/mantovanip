## \`what-i-build\`

### 🏥 DolceMed
**SaaS para clínicas médicas e odontológicas**

Plataforma em evolução para gestão de clínicas, com onboarding, autenticação, profissionais, pacientes, serviços, agenda, disponibilidade, consultas e agendamento público.

**Stack:** TanStack Start · React · TypeScript · Supabase · PostgreSQL · Vercel

### 🎯 Prospecta
**SaaS para prospecção comercial**

Ferramenta para encontrar oportunidades, organizar leads, trabalhar CRM, histórico de contatos, classificação de oportunidades e abordagem comercial.

**Stack:** TanStack Start · React · TypeScript · Supabase · PostgreSQL · APIs

### ⚡ MantovaniSys
**Web development + digital products**

Minha operação para criação de sites, landing pages, presença digital, SEO local e soluções web para empresas.

Também funciona como laboratório para testar interfaces, templates, produtos e novas ideias.

### 🌐 Projetos para empresas

Projetos web desenvolvidos para negócios locais.

Da estrutura visual ao código, publicação e presença digital.
