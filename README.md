## Sobre mim

Sou **Paulo Mantovani**, desenvolvedor e criador de produtos digitais.

Minha trajetória no GitHub começou com estudos, exercícios e pequenos projetos web. Com o tempo, o foco mudou: passei a transformar problemas reais em **sites, sistemas, ferramentas de prospecção e produtos SaaS completos**.

Hoje trabalho principalmente com:

- desenvolvimento de sites institucionais e landing pages;
- aplicações web e sistemas internos;
- SaaS com autenticação, banco de dados e regras de negócio;
- dashboards, CRM e fluxos operacionais;
- presença digital e SEO local;
- integrações com APIs e serviços externos;
- GitHub, CI/CD e publicação de aplicações;
- arquitetura e evolução de produtos do MVP até uma versão utilizável.

Gosto especialmente da parte em que **design, negócio e tecnologia precisam funcionar juntos**.

## Projetos que representam meu trabalho

### 🏥 DolceMed — SaaS para clínicas

Uma plataforma de gestão para clínicas médicas e odontológicas.

O projeto evoluiu de uma ideia inicial para uma aplicação com:

- cadastro e onboarding de clínicas;
- autenticação e confirmação de e-mail;
- profissionais e membros da clínica;
- agenda e disponibilidade;
- pacientes;
- serviços;
- consultas e ciclo de atendimento;
- agendamento público;
- páginas institucionais por clínica;
- banco PostgreSQL com Supabase;
- controle de acesso por clínica.

**Stack:** TanStack Start · React · TypeScript · Supabase · PostgreSQL · Vercel

### 🎯 Prospecta — Prospecção comercial

Uma aplicação SaaS criada para ajudar freelancers e agências a encontrar empresas e oportunidades comerciais.

O produto trabalha com:

- prospecção por região e segmento;
- identificação de oportunidades digitais;
- organização de leads;
- CRM;
- histórico de contatos;
- abordagem via WhatsApp;
- classificação de oportunidades;
- geração e organização de projetos.

**Stack:** TanStack Start · React · TypeScript · Supabase · PostgreSQL · APIs e fontes públicas

### ⚡ MantovaniSys — Produtos e serviços digitais

Minha operação para desenvolvimento de sites, presença digital e soluções web para empresas.

Além dos projetos comerciais, o MantovaniSys funciona como laboratório para testar ideias, templates, experiências de usuário e novas soluções.

**Foco:** sites · SEO local · Google Business · landing pages · sistemas web · SaaS

### 🌐 Projetos para empresas

Também desenvolvi sites e experiências digitais para negócios locais, trabalhando desde a estrutura visual até publicação e presença digital.

Entre os projetos estão trabalhos para empresas como:

- Assis Ferragens
- Advalef Borges
- Vih Borba
- Kbella Flor

Cada projeto trouxe um problema diferente de comunicação, posicionamento ou conversão — e isso faz parte do que mais gosto no desenvolvimento.

## O que estou construindo

Meu foco atual está menos em simplesmente **fazer um site** e mais em construir produtos que resolvam uma operação inteira.

```text
Ideia
  ↓
UX / Interface
  ↓
Frontend
  ↓
Backend + Banco de dados
  ↓
Autenticação + Regras de negócio
  ↓
Testes
  ↓
GitHub / CI
  ↓
Deploy
  ↓
Produto funcionando
```

É essa visão de ponta a ponta que tento levar para cada projeto.

## Uma coisa sobre meu trabalho

Não quero ficar preso a uma tecnologia específica.

A tecnologia muda. O problema do cliente continua existindo.

Por isso, meu objetivo é entender o que precisa ser construído, escolher uma arquitetura coerente e entregar algo que **realmente possa ser usado**.

**Código é parte do produto. Não é o produto inteiro.**
